Core Architecture

Engineered for Extreme Pipeline Reliability

Every layer is designed to look like N bored humans rather than 1 fast robot, while respecting upstream platform terms.

Log-Normal Jitter Pacing

Avoids naive periodic sleep intervals. Delays are modeled with log-normal distributions and occasional long pauses that reflect human browsing physics.

Swappable Source Adapters

Ingestion feeds sit behind an abstract SourceAdapter interface. Swapping a source or adding new partners requires zero changes downstream.

Schema-Drift Quarantine

Every run compares output field structures against known-good schema snapshots. Format mutations fail loudly into dead-letter queues rather than corrupting databases.

De-escalating Fallback Ladder

When an endpoint throttles: cool down session → rotate proxy node → global volume drop → fail over to backup source → alert human. Never escalates or attacks bot defenses.

Strict ToS Attribution

Full compliance with platform feeds: direct canonical URLs without tracking wrappers or redirects, and explicit source attribution recorded in every document.

Idempotent MongoDB Store

Unique compound indexing on (source, external_id) guarantees seamless updates and zero duplicated documents across repeated runs.
